前端重点改造
  • 接口类型新增：1=SQL查询，2=存储过程。
  • 接口类型由 Tab 固定：SQL Tab 传 1，存储过程 Tab 传 2。
  • type=2 时隐藏 SQL 拼接字段。
  • 新增 procedureName，保存时必填。
  • 参数表保留 type；新增 direction、jdbcType、orderNo。
  • 每个参数都填写名称、编码、类型、方向、JDBC 类型和顺序；同一接口内编码不能重复。
  • CURSOR 只能配置为 OUT，且参数类型固定为“列表”。
  • 参数排序直接编辑 orderNo，值必须从 1 开始连续。
  • JDBC 类型下拉展示名称，保存请求提交数值 1~8；后端会转换为字符串。
  • 调用预览不提供手动按钮，按完整参数配置自动显示。
参数方向规则
方向提交值调用方
IN1可传入；未传或 null 按 SQL NULL 绑定
OUT2不传，由过程返回
INOUT3可传入且返回；未传或 null 按 SQL NULL 绑定
参数类型
  • 参数类型用于说明业务数据类型；存储过程不配置必填、默认值和业务校验。
  • OUT 标量参数用于说明返回值业务类型，应配置并展示。
  • OUT CURSOR 参数固定为列表，表示返回结果集。
  • 字段值沿用原接口参数 type：字符串、整数、浮点数、日期、列表。
  • JDBC 类型用于入参转换和数据库绑定，参数类型用于业务展示。
JDBC 类型
  • 下拉展示类型名称，保存请求提交 1~8；后端入库统一保存为字符串。
  • VARCHAR：VARCHAR2、CHAR。
  • INTEGER/BIGINT/DECIMAL：Oracle NUMBER。
  • DATE：yyyy-MM-dd 或 yyyy-MM-dd HH:mm:ss。
  • TIMESTAMP：yyyy-MM-dd HH:mm:ss。
  • CLOB：长文本，支持 IN、OUT、INOUT，参数类型选择“字符串”。
  • CURSOR：Oracle SYS_REFCURSOR。
  • 选择 CURSOR 时 direction 必须为 OUT。
  • direction 为 IN/INOUT 时，JDBC 类型下拉不展示 CURSOR。
orderNo 的作用
  • Oracle CallableStatement 按位置绑定。
  • orderNo=1 对应第一个问号。
  • 顺序配置错会导致参数绑定错位。
  • 同一接口内不允许重复，且必须从 1 开始连续编号。
  • 保存时校验为连续正整数，并按升序回显。
参数表交互说明
  • 新增参数只追加一行，默认 orderNo 取当前参数数量+1。
  • 删除操作只保留行内删除。
  • 所有方向均不展示、配置必填、默认值和业务校验字段。
  • IN/INOUT 保留 JDBC 类型转换；未传或 null 按 SQL NULL 绑定。
  • 选择 CURSOR 时，方向自动设为 OUT 并禁用修改。
  • 选择 CURSOR 时，参数类型自动设为“列表”并禁用修改；非 OUT 方向的 JDBC 下拉不展示 CURSOR。
  • 如果已选 CURSOR 后改方向，需先清空或切换 JDBC 类型。
调用预览说明
  • 新增页不放“生成预览”按钮。
  • procedureName 为空时显示待配置。
  • 任一参数缺少名称、编码、类型、orderNo、direction、jdbcType 时显示待配置。
  • 配置完整后按参数数量显示 `{ call ...(?, ?) }`。
  • 该预览只表示绑定结构，不校验数据库过程是否存在。
